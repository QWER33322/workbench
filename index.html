🔄 数据管理

📊 当前数据概况
📤 备份数据（更新前必做）
💡 每次更新页面前，先点「导出备份」，保存一份 JSON 文件到手机。
如果更新后数据丢失，用「导入恢复」一键还原。
📥 导入恢复
⚠️ 导入会覆盖当前所有数据，请确认备份文件正确。
支持导入之前导出的 .json 备份文件。
📋 更新操作指南
场景1：同浏览器更新（数据不丢）
① 我更新代码后，你刷新页面 → 数据自动还在 ✅
② 无需任何操作

场景2：换了新 HTML 文件
① 打开旧页面 → 点「导出备份」→ 保存 .json
② 打开新页面 → 点「导入恢复」→ 选 .json → 数据回来 ✅

场景3：换手机/清缓存
① 旧手机打开页面 → 「导出备份」→ 传到新手机
② 新手机打开工作台 → 「导入恢复」→ 选 .json ✅

场景4：数据不小心丢了
① 只要之前「导出备份」过 → 找到 .json → 「导入恢复」
② 数据完整恢复，包括所有模块的所有记录 ✅
